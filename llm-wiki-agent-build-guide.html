先建立心智模型

三个与 RAG 相反的判断，决定了整个架构

不先理解这三点，你会照着 RAG 的直觉写，然后处处别扭。

编译一次，持续维护

知识在导入时就被 LLM 编译进 wiki/，之后只做增量维护；查询只是读取。RAG 相反——每次提问都重新检索，知识永不沉淀。

Schema 即程序

CLAUDE.md / AGENTS.md / GEMINI.md 同时是给智能体的指令、页面格式定义，以及被脚本读取的常量（SCHEMA_FILE）。一份文件，三处复用。

文件系统即数据库

raw/ 只读、wiki/ 由 Agent 独占写入、graph/ 可随时重建。没有数据库、没有服务、没有消息队列，一切皆 Markdown + YAML frontmatter。

Architecture · 架构与数据流

四个目录、一列脚本，构成一条完整链路

Minimal Viable · M0

先跑通一次 ingest → query，别碰图谱

第一个里程碑只需要三个脚本和一个共享底座。目标不是功能完整，而是亲眼看到「文档进去，知识出来」这条主链路。

输入形式
raw/<path>.md → UTF-8 str；命令行参数 raw_path: str；query 的问题 → str
输出形式
磁盘 wiki/{sources,entities,concepts}/*.md + index.md + log.md；query 返回带 [[wikilink]] 引用的答案 str
数据案例
raw/4-re.md → 若干 wiki/*.md 页面、index.md 追加条目、log.md 前插一行；再提问 → 返回含 [[检索增强生成]] 的回答
1

建目录

raw/ 与 wiki/{sources,entities,concepts}，再加一个空的 index.md、log.md。

2

写最小的 Schema

用 CLAUDE.md 约定页面格式：路径规则、frontmatter 字段、正文必须用 [[wikilink]] 互链。

3

写共享底座

tools/_utils.py：路径常量、safe_rel_path 与 write_page（路径归一 + 落盘）、call_llm、sha256、extract_wikilinks，以及更新索引/日志的 append_index、append_log。后面所有脚本都依赖它。

4

写写入链路

tools/ingest.py：读源文档 → 一次 LLM 调用 → 解析 JSON → 写页面 → 更新 index.md / log.md。

5

写读取链路

tools/query.py：读 index.md → 关键词匹配相关页 → 组装上下文 → LLM 合成带引用的回答。

6

验收

放一个 .md 进 raw/，跑 ingest 生成页面并让 index.md 出现新条目；再 query 提问，召回非空、答案里能看到 [[链接]]。

教学用最小实现 · 非官方源码

下面的代码是为讲清架构而重写的简化版，命名与真实仓库一致，但省略了校验、缓存与错误处理。真实实现以仓库为准——这正好对应 M1 之后要补的东西。路径统一以 wiki/ 为根：write_page 剥掉模型多写的 wiki/ 前缀，index.md 只存相对路径（sources/x.md），这样 query、health 才能用 WIKI_DIR / p 正确拼出磁盘路径；否则会落成 wiki/wiki/…。

tools/_utils.py · 共享底座

# 所有工具的唯一依赖：路径、LLM、哈希、wikilink
import os, re, json, hashlib
from datetime import datetime
from pathlib import Path

# 环境自愈：代理软件常把 "[::1]" 塞进 NO_PROXY，httpx 会把它当端口，报
# Invalid port: ':1]'。litellm 在 import 阶段就可能联网，必须先清掉。
os.environ["NO_PROXY"] = ",".join(
    t for t in os.environ.get("NO_PROXY", "").replace("[::1]", "").split(",") if t)
from litellm import completion

ROOT = Path(__file__).resolve().parent.parent
RAW_DIR, WIKI_DIR = ROOT / "raw", ROOT / "wiki"
INDEX, LOG = WIKI_DIR / "index.md", WIKI_DIR / "log.md"
SCHEMA_FILE = ROOT / "CLAUDE.md"
MODEL = os.getenv("LLM_MODEL", "deepseek/deepseek-chat")

def sha256(text: str) -> str:
    return hashlib.sha256(text.encode("utf-8")).hexdigest()

def call_llm(system: str, user: str, model: str = MODEL, json_mode: bool = False) -> str:
    # json_mode 只在需要结构化输出时开（ingest）；query 要自由文本，开了会 400。
    # DeepSeek 需显式传 key：key 为空时 litellm 会发 Bearer 空 token → 401 governor。
    kw = {}
    if model.startswith("deepseek"):
        key = os.getenv("DEEPSEEK_API_KEY", "").strip()
        if not key:
            raise SystemExit("DEEPSEEK_API_KEY 为空：请先在当前终端设置它。")
        kw["api_key"] = key
        kw["api_base"] = os.getenv("DEEPSEEK_API_BASE", "https://api.deepseek.com")
        if json_mode:
            kw["response_format"] = {"type": "json_object"}
    resp = completion(
        model=model,
        messages=[{"role": "system", "content": system},
                  {"role": "user", "content": user}],
        **kw,
    )
    return resp.choices[0].message.content

WIKILINK_RE = re.compile(r"\[\[([^\]]+)\]\]")
def extract_wikilinks(text: str) -> list[str]:
    return WIKILINK_RE.findall(text)

# 路径归一：剥掉模型多写的 wiki/ 前缀、拦截 ..、替换 Windows 非法字符、补 .md。
# 索引与 query 都以 WIKI_DIR 为根（如 sources/x.md），写盘前必须先归一。
_ILLEGAL = re.compile(r'[<>:"/\\|?*\x00-\x1f]')
def safe_rel_path(rel: str) -> str:
    parts = [p for p in str(rel).strip().replace("\\", "/").split("/") if p not in ("", ".")]
    if parts and parts[0].lower() == "wiki":
        parts = parts[1:]
    parts = [p for p in parts if p != ".."]           # 拦目录穿越
    cleaned = [_ILLEGAL.sub("-", p).strip().rstrip(".") for p in parts]
    cleaned = [p for p in cleaned if p]
    if not cleaned:
        cleaned = ["untitled.md"]                     # 空输入兜底
    if not cleaned[-1].endswith(".md"):
        cleaned[-1] += ".md"
    return "/".join(cleaned)

def write_page(rel: str, content: str) -> Path:
    base = WIKI_DIR.resolve()
    path = (base / safe_rel_path(rel)).resolve()
    # 安全校验：解析后的路径必须仍在 wiki 内，否则拒绝写入
    if path != base and base not in path.parents:
        raise ValueError(f"拒绝写出 wiki 目录之外: {rel!r}")
    path.parent.mkdir(parents=True, exist_ok=True)
    path.write_text(content, encoding="utf-8")
    return path

# index.md 的三个分区；query.py 靠 ](path.md) 正则扫描这里召回页面
INDEX_SECTIONS = (("sources", "## Sources"),
                  ("entities", "## Entities"),
                  ("concepts", "## Concepts"))

def append_index(entries: list[tuple[str, str, str]]) -> None:
    # entries: [(分类, 标题, 相对路径), ...]，先解析旧内容再整体重写，天然去重
    sections = {k: [] for k, _ in INDEX_SECTIONS}
    if INDEX.exists():
        current = None
        for line in INDEX.read_text(encoding="utf-8").splitlines():
            if line.startswith("## "):
                current = line[3:].strip().lower()
            m = re.match(r"- \[(.+?)\]\(([^)]+\.md)\)", line)
            if m and current in sections:
                sections[current].append((m.group(1), m.group(2)))
    for key, title, rel in entries:
        if (title, rel) not in sections.setdefault(key.lower(), []):
            sections[key.lower()].append((title, rel))
    out = ["# 索引", ""]
    for key, heading in INDEX_SECTIONS:
        if sections.get(key):
            out.append(heading)
            out += [f"- [{t}]({r})" for t, r in sections[key]]
            out.append("")
    INDEX.write_text("\n".join(out).rstrip() + "\n", encoding="utf-8")

def append_log(entry: str) -> None:
    # 前插：最新记录在最上方；首次写入补上 # 日志 标题
    prev = LOG.read_text(encoding="utf-8").strip() if LOG.exists() else ""
    block = f"## {datetime.now():%Y-%m-%d %H:%M}\n{entry}"
    if not prev:
        LOG.write_text(f"# 日志\n\n{block}\n", encoding="utf-8")
    elif prev.startswith("# "):
        head, _, rest = prev.partition("\n")
        LOG.write_text(f"{head}\n\n{block}\n\n{rest.lstrip()}\n", encoding="utf-8")
    else:
        LOG.write_text(f"{block}\n\n{prev}\n", encoding="utf-8")

tools/ingest.py · 最小写入链路

import sys, json
from pathlib import Path
from tools._utils import (RAW_DIR, WIKI_DIR, INDEX, SCHEMA_FILE, call_llm,
                          write_page, append_index, append_log)

PROMPT = """你在维护一个 Markdown 知识库。
严格返回一个 JSON 对象，不要解释、不要代码围栏。
字段：title, source_page, entity_pages[], concept_pages[], log_entry
每个页面形如 {path, content}，content 用 [[wikilink]] 互链。"""

def parse_json(text: str) -> dict:
    text = text.strip()
    if text.startswith("```"):
        text = text.split("\n", 1)[1].rsplit("```", 1)[0]
    return json.loads(text)

def main(raw_path: str) -> None:
    raw = (RAW_DIR / raw_path).read_text(encoding="utf-8")
    schema = SCHEMA_FILE.read_text(encoding="utf-8")
    index = INDEX.read_text(encoding="utf-8") if INDEX.exists() else ""
    out = parse_json(call_llm(PROMPT,
        f"{schema}\n\n# 现有索引\n{index}\n\n# 源文档\n{raw}",
        json_mode=True))   # ingest 需结构化 JSON；query 不能传
    # 写页面时用 write_page 的返回值收 (分类, 标题, 相对路径)：
    # 索引必须存 WIKI_DIR 相对路径，query 才能用 WIKI_DIR / p 打开
    page = write_page(out["source_page"]["path"], out["source_page"]["content"])
    written = [("sources", out["title"], page.relative_to(WIKI_DIR).as_posix())]
    for p in out["entity_pages"]:
        page = write_page(p["path"], p["content"])
        written.append(("entities", Path(p["path"]).stem,
                        page.relative_to(WIKI_DIR).as_posix()))
    for p in out["concept_pages"]:
        page = write_page(p["path"], p["content"])
        written.append(("concepts", Path(p["path"]).stem,
                        page.relative_to(WIKI_DIR).as_posix()))
    # 关键：更新 index.md，否则 query 永远召回不到页面
    append_index(written)
    append_log(out.get("log_entry") or f"ingest {out['title']}")
    print("ingested:", out["title"])

if __name__ == "__main__":
    main(sys.argv[1])

tools/query.py · 最小读取链路

import sys, re
from tools._utils import INDEX, WIKI_DIR, call_llm

def find_relevant_pages(question: str, index: str) -> list[str]:
    paths = re.findall(r"\]\(([^)]+\.md)\)", index)
    tokens = set(re.findall(r"[a-z0-9]+", question.lower()))
    tokens |= {question[i:i + 2] for i in range(len(question) - 1)}  # CJK 2 字滑窗
    scored = []
    for p in paths:
        text = (WIKI_DIR / p).read_text(encoding="utf-8").lower()
        score = sum(text.count(t) for t in tokens)
        if score:
            scored.append((score, p))
    scored.sort(reverse=True)
    return [p for _, p in scored[:15]]

def main(question: str) -> None:
    index = INDEX.read_text(encoding="utf-8")
    pages = find_relevant_pages(question, index)
    context = "\n\n".join((WIKI_DIR / p).read_text(encoding="utf-8") for p in pages)
    print(call_llm(
        "只用给定页面回答，引用时写成 [[页面名]]。",
        f"# 上下文\n{context}\n\n# 问题\n{question}"))

if __name__ == "__main__":
    main(sys.argv[1])

M1

Schema 约束与后置校验

改动 · tools/_utils.py · tools/ingest.py

难度 · 中
输入形式
raw/<path>.md、CLAUDE.md、wiki/index.md → str（索引可为空串）；LLM 响应 → 原始 str（可能带代码围栏或前后闲话）
输出形式
parse_json_from_response → dict；validate_links → list[str]（空列表 = 通过）；通过才落盘 wiki/*.md + index.md + log.md，失败则零改动
数据案例
LLM 文本 ```json {"pages":[…] }``` → {"pages":[…]}；[[NotExist]] → ["断链：sources/rag-basics.md → [[NotExist]]"]

输入

  • raw/<path>.md —— 待编译的源文档正文
  • CLAUDE.md（SCHEMA_FILE）—— 页面格式、frontmatter 与 [[wikilink]] 规范，拼进 prompt 约束模型
  • wiki/index.md —— 现有索引，随 prompt 一并传入（不存在时按空串处理），让模型复用已有页面名而不是另造新词
  • LLM 返回的一段原始文本——理论上是 JSON，实际可能带 ```json 代码围栏或前后闲话

输出

  • 成功：wiki/{sources,entities,concepts}/*.md 页面、可选 overview.md；index.md 追加条目（含 ## Overview 分区）、log.md 前插本次记录
  • 失败（断链）：打印每条断链后 return，磁盘零改动

方法作用

  • parse_json_from_response(text) → dict：把 LLM 原始文本洗成可用的 dict。先用正则剥掉开头/结尾的 ``` 围栏（兼容单行围栏，避免 split 越界），再截取首个 { 到末个 } 之间的内容交给 json.loads；找不到花括号则抛 ValueError。
  • validate_links(out, index) → list[str]：写入前的断链闸门。先构造合法目标集合 —— 本次所有页面的标题、文件名 stem、.md 全名，外加从 index.md 正则提取的已有页面；再遍历每个页面内容里的 [[链接]]（[[A|别名]] 只取 A），凡不在目标集内即记一条错误。返回空列表代表校验通过。
  • main(raw_path) → None：串起整条流程的编排器 —— 读源文档 / Schema / 索引 → 调 LLM → 解析 JSON → 先校验 → 校验通过才逐个 write_page → 追加 append_index / append_log。

实现内容与功能

  • 把 CLAUDE.md 注入 prompt，让 LLM 按固定 frontmatter 与 [[wikilink]] 规范输出
  • 容错解析：剥离 ```json 代码围栏（正则兼容单行围栏），再截取第一个 { 到最后一个 }
  • 写入前校验：检查断链——所有 [[链接]] 必须能在「本次新页面 + index.md 已有页面」里找到目标；支持 [[A|别名]] 语法
  • 路径归一：校验与写盘共用 M0 已定义的 safe_rel_path，避免「校验通过却写成断链」
  • 写入 overview.md 并登记进 index.md 的 ## Overview 分区；log.md 仍由 append_log 写入
  • prompt 字段补上 overview_update，并以 out.get() 兜底，缺字段不再 KeyError

如何实现

解析与校验是「防幻觉」的两道闸门：解析保证拿到结构化数据，校验保证引用闭合。任何一条坏写入都会污染整个索引，所以顺序是「先全部校验、再统一写盘」——校验失败在第一步就中止，此时还没碰过磁盘，不会留下半成品。

验收标准

故意让输出包含一个不存在的 [[NotExist]]，ingest 应打印断链并拒绝写入，且 wiki/ 无任何新文件。

# 路径归一 safe_rel_path 与 write_page 已在 M0 定义，这里不重复实现。
# 容错 JSON 解析：先剥离代码围栏（兼容 ```json 与单行围栏），
# 再用 raw_decode 从第一个 { 起解析——模型在 JSON 后追加说明也不会抛 Extra data。
def parse_json_from_response(text: str) -> dict:
    text = text.strip()
    if text.startswith("```"):
        text = re.sub(r"^```[a-zA-Z]*\s*", "", text)   # 去开头围栏
        text = re.sub(r"\s*```$", "", text)            # 去结尾围栏
    start = text.find("{")
    if start == -1:
        raise ValueError("响应里找不到 JSON")
    obj, _ = json.JSONDecoder().raw_decode(text[start:])   # 只解析第一个完整对象
    return obj

字段：title, source_page, entity_pages[], concept_pages[], overview_update, log_entry

# 写入前拦截断链：目标集 = 本次新页面标题/文件名 + index 已有页面。
# source 页文件名是 kebab-case 而标题是 Source Title，故标题也收；
# 同时收 stem 与 .md 全名，兼容 [[x]] 和 [[x.md]]；[[A|别名]] 只比较 A。
def validate_links(out: dict, index: str) -> list[str]:
    errors = []
    pages = [out["source_page"], *out["entity_pages"], *out["concept_pages"]]
    titles = {out["title"]}                          # 源页标题（kebab 文件名的原形）
    for p in pages:
        rel = safe_rel_path(p["path"])
        titles.add(Path(rel).stem)
        titles.add(Path(rel).name)
    # index 行是 "- [显示标题](路径.md)"：标题与路径 stem 都要收。
    # 只收 stem 会漏掉中文标题（源页是 kebab 文件名），
    # 于是 [[检索增强生成]] 链到已存在的源页会被误判为断链。
    for title, path in re.findall(r"- \[(.+?)\]\(([^)]+\.md)\)", index):
        titles.add(title)
        titles.add(Path(safe_rel_path(path)).stem)
    for p in pages:
        for raw in extract_wikilinks(p["content"]):
            target = raw.split("|", 1)[0].strip()      # [[A|别名]] 取 A
            if target not in titles:
                errors.append(f"断链：{p['path']} → [[{raw}]]")
    return errors

def main(raw_path: str) -> None:
    raw = (RAW_DIR / raw_path).read_text(encoding="utf-8")
    schema = SCHEMA_FILE.read_text(encoding="utf-8")
    index = INDEX.read_text(encoding="utf-8") if INDEX.exists() else ""
    out = parse_json_from_response(call_llm(PROMPT,
        f"{schema}\n\n# 现有索引\n{index}\n\n# 源文档\n{raw}",
        json_mode=True))   # ingest 需结构化 JSON

    # 第一步就拦断链：不通过直接 return，此时尚未碰过磁盘
    if (errors := validate_links(out, index)):
        print("校验失败，中止写入：")
        for e in errors:
            print("  -", e)
        return

    # 校验全过才开始写盘；用 write_page 返回值收 WIKI_DIR 相对路径
    page = write_page(out["source_page"]["path"], out["source_page"]["content"])
    written = [("sources", out["title"], page.relative_to(WIKI_DIR).as_posix())]
    for p in out["entity_pages"]:
        page = write_page(p["path"], p["content"])
        written.append(("entities", Path(p["path"]).stem,
                        page.relative_to(WIKI_DIR).as_posix()))
    for p in out["concept_pages"]:
        page = write_page(p["path"], p["content"])
        written.append(("concepts", Path(p["path"]).stem,
                        page.relative_to(WIKI_DIR).as_posix()))
    if (overview := out.get("overview_update")):       # 缺字段也不崩
        # 模型可能把它写成 {path, content} 对象；write_page 只收 str，先取出正文
        text = overview.get("content") if isinstance(overview, dict) else overview
        write_page("overview.md", text)
        written.append(("overview", "Overview", "overview.md"))
    append_index(written)  # 校验通过后再更新索引与日志
    append_log(out.get("log_entry") or f"ingest {out['title']}")

import json, re, sys
from tools._utils import WIKI_DIR, INDEX, LOG

def stub_pages() -> list[str]:
    bad = []
    for p in WIKI_DIR.rglob("*.md"):
        body = re.sub(r"^---.*?---", "", p.read_text(encoding="utf-8"), flags=re.S).strip()
        if len(body) < 40:                       # 除 frontmatter 外几乎没内容
            bad.append(p.relative_to(WIKI_DIR).as_posix())
    return bad

def index_mismatch() -> tuple[list, list]:
    index = INDEX.read_text(encoding="utf-8")
    listed = set(re.findall(r"\]\(([^)]+\.md)\)", index))
    on_disk = {str(p.relative_to(WIKI_DIR)).replace("\\", "/")
               for p in WIKI_DIR.rglob("*.md")}
    on_disk.discard("index.md"); on_disk.discard("log.md")
    return sorted(on_disk - listed), sorted(listed - on_disk)

def log_coverage() -> list[str]:
    log = LOG.read_text(encoding="utf-8") if LOG.exists() else ""
    return [s for s in (p.stem for p in (WIKI_DIR / "sources").glob("*.md"))
            if s not in log]

def main(as_json: bool) -> None:
    unindexed, missing = index_mismatch()
    report = {"stubs": stub_pages(), "unindexed": unindexed,
              "missing_files": missing, "untracked": log_coverage()}
    if as_json:
        print(json.dumps(report, ensure_ascii=False, indent=2))
        return
    for k, items in report.items():
        print(f"{k}: {len(items)}")
        for item in items:
            print("  -", item)

if __name__ == "__main__":
    main("--json" in sys.argv)

import json
from tools._utils import WIKI_DIR, extract_wikilinks

def pass1() -> tuple[dict, list]:
    nodes, edges, seen = {}, [], set()
    for p in WIKI_DIR.rglob("*.md"):
        rel = str(p.relative_to(WIKI_DIR)).replace("\\", "/")
        title = rel[:-3]                          # 去掉 .md
        nodes[title] = {"id": title, "path": rel}
        for link in extract_wikilinks(p.read_text(encoding="utf-8")):
            key = tuple(sorted((title, link)))    # 无向去重
            if key in seen:
                continue
            seen.add(key)
            edges.append({"source": title, "target": link,
                          "type": "EXTRACTED", "confidence": 1.0})
    return nodes, edges

HTML = """<!doctype html><meta charset="utf-8">
<div id="g" style="height:100vh"></div>
<script src="https://unpkg.com/vis-network/standalone/umd/vis-network.min.js"></script>
<script>
const d = {nodes: %s, edges: %s};
new vis.Network(document.getElementById('g'), {
  nodes: new vis.DataSet(d.nodes.map(n => ({id:n.id, label:n.id}))),
  edges: new vis.DataSet(d.edges.map(e => ({from:e.source, to:e.target})))
}, {physics:{stabilization:true}});
</script>"""

def render(nodes: dict, edges: list, out_dir) -> None:
    html = HTML % (json.dumps(list(nodes.values()), ensure_ascii=False),
                   json.dumps(edges, ensure_ascii=False))
    (out_dir / "graph.html").write_text(html, encoding="utf-8")
    (out_dir / "graph.json").write_text(
        json.dumps({"nodes": list(nodes.values()), "edges": edges},
                   ensure_ascii=False, indent=2), encoding="utf-8")

# Pass 2：推断隐含关系，低于阈值的猜测直接丢弃
def build_inferred_edges(nodes, cache, checkpoint) -> list:
    edges = []
    for title, meta in nodes.items():
        text = read_page(meta["path"])[:2000]     # 控制成本
        key = sha256(text)
        if key in cache:                          # 命中缓存，零调用
            edges += cache[key]
            continue
        candidates = ", ".join(t for t in nodes if t != title)
        raw = call_llm(PROMPT_EDGES, f"{text}\n\n候选节点：{candidates}")
        result = parse_json_from_response(raw)
        kept = [e for e in result["edges"] if e["confidence"] >= 0.7]
        kept = [{**e, "source": title, "type": "INFERRED"} for e in kept]
        cache[key] = kept
        save_checkpoint(checkpoint, key, kept)    # 追加写，崩溃可续
        edges += kept
    return edges

代码 · Louvain 社区发现 + JSONL 断点续跑

import json
import networkx as nx
from networkx.algorithms.community import louvain_communities

def communities(nodes: dict, edges: list) -> int:
    G = nx.Graph()
    G.add_nodes_from(nodes)
    G.add_weighted_edges_from(
        (e["source"], e["target"], e.get("confidence", 1.0)) for e in edges)
    comms = louvain_communities(G, seed=42)
    for i, members in enumerate(comms):
        for m in members:
            nodes[m]["community"] = i
    return len(comms)

def load_checkpoint(path) -> dict:
    cache = {}
    if path.exists():
        for line in path.read_text(encoding="utf-8").splitlines():
            rec = json.loads(line)
            cache[rec["key"]] = rec["edges"]
    return cache

def save_checkpoint(path, key: str, edges: list) -> None:
    with path.open("a", encoding="utf-8") as f:
        f.write(json.dumps({"key": key, "edges": edges},
                           ensure_ascii=False) + "\n")

from collections import defaultdict
from tools._utils import WIKI_DIR, call_llm, extract_wikilinks

def structural_report() -> dict:
    inbound = defaultdict(int)
    for p in WIKI_DIR.rglob("*.md"):
        for link in extract_wikilinks(p.read_text(encoding="utf-8")):
            inbound[link] += 1
    pages = {p.stem for p in WIKI_DIR.rglob("*.md")}
    focus = {"index", "log", "overview"}
    return {
        "orphans": sorted(t for t in pages
                          if inbound[t] == 0 and t not in focus),
        "broken": sorted(t for t in inbound if t not in pages),
        "missing_entities": sorted(t for t, n in inbound.items()
                                   if n >= 3 and t not in pages),
    }

def semantic_review(sample: int = 20) -> str:
    pages = list(WIKI_DIR.rglob("*.md"))[:sample]
    digest = "\n\n".join(p.read_text(encoding="utf-8")[:1500] for p in pages)
    return call_llm("找出跨页面矛盾、过时摘要与数据缺口，输出条目清单。", digest)

# tools/heal.py —— 为缺失实体自动补页，绝不越界写入
import re
from pathlib import Path
from tools._utils import WIKI_DIR, call_llm, parse_json_from_response

def sanitize_filename(name: str) -> str:
    name = re.sub(r"[^\w\u4e00-\u9fff-]", "_", name).strip("._")
    return name[:80] or "untitled"

def safe_path(rel: str) -> Path:
    p = (WIKI_DIR / rel).resolve()
    if WIKI_DIR.resolve() not in p.parents:        # 禁止目录逃逸
        raise ValueError(f"路径逃出 wiki/：{rel}")
    return p

def heal(missing: list[str]) -> None:
    for name in missing:
        context = gather_mentions(name)            # 收集提及它的片段
        out = parse_json_from_response(call_llm(
            "根据上下文为一个实体写简介页，含「## 概述」和「## 相关 [[链接]]」。",
            f"实体：{name}\n上下文：{context}"))
        rel = f"entities/{sanitize_filename(name)}.md"
        path = safe_path(rel)
        path.parent.mkdir(parents=True, exist_ok=True)
        path.write_text(out["content"], encoding="utf-8")

M6

增量刷新与多格式

改动 · 新增 tools/refresh.py · tools/file_to_md.py · tools/pdf2md.py

难度 · 中
输入形式
raw/ 目录（PDF / DOCX / PPTX / EPUB / MD 混排）；.refresh-cache.json（路径 → SHA256 指纹）
输出形式
docs/raw-md/*.md（格式转换产物）；仅对指纹变化的文件调用 ingest.py，其余跳过
数据案例
raw/vector-search.docx → docs/raw-md/vector-search.md；二次 refresh 指纹全同 → 0 次重编译

实现内容与功能

  • refresh.py：对 raw/ 每个文件做 SHA256，只重编译新增 / 改动的文件
  • file_to_md.py：markitdown 批量把 PDF / DOCX / PPTX / EPUB 等转 Markdown，拒绝静默覆盖
  • pdf2md.py：arXiv / PDF 高保真转换，后端从 marker 自动降级到 pymupdf4llm
  • 带 tqdm 进度，碰撞可见

如何实现

内容级增量靠哈希而不是时间戳；多格式转换是「可重建的输入预处理」，与 wiki 写入解耦，所以转换失败也不会污染知识层。

验收标准

放 3 个文件连跑两次 refresh，第二次 0 次 ingest；改其中一个，只有它被重编译。

代码 · tools/refresh.py（内容级增量）

# tools/refresh.py —— 只有源文件内容变化才重编译
import json
from tools._utils import RAW_DIR, sha256
from tools.ingest import main as ingest

STATE = RAW_DIR.parent / ".refresh-cache.json"

def refresh() -> None:
    state = json.loads(STATE.read_text(encoding="utf-8")) if STATE.exists() else {}
    for raw in RAW_DIR.rglob("*"):
        if raw.is_dir():
            continue
        digest = sha256(raw.read_text(encoding="utf-8", errors="ignore"))
        if state.get(str(raw)) != digest:          # 新增或已变化
            ingest(raw.relative_to(RAW_DIR).as_posix())
            state[str(raw)] = digest
    STATE.write_text(json.dumps(state, ensure_ascii=False, indent=2),
                     encoding="utf-8")

代码 · tools/file_to_md.py + tools/pdf2md.py

# tools/file_to_md.py —— markitdown 批量转换，拒绝静默覆盖
from pathlib import Path
from markitdown import MarkItDown
from tqdm import tqdm

def convert_tree(src: Path, dst: Path) -> None:
    md = MarkItDown()
    for f in tqdm([p for p in src.rglob("*") if p.is_file()]):
        target = (dst / f.relative_to(src)).with_suffix(".md")
        if target.exists():
            print("跳过（已存在）：", target)
            continue
        target.parent.mkdir(parents=True, exist_ok=True)
        target.write_text(md.convert(str(f)).text_content, encoding="utf-8")

# tools/pdf2md.py —— 高保真后端自动降级
def pdf_to_md(path: str, backend: str = "auto") -> str:
    if backend in ("auto", "marker"):
        try:
            from marker.converters.pdf import PdfConverter
            return PdfConverter().convert(path).markdown
        except ImportError:
            pass                                   # 回退到轻量方案
    import pymupdf4llm
    return pymupdf4llm.to_markdown(path)

Achievements & Pitfalls

设计亮点与常见的坑

哪些是仓库里能证实的事实，哪些是学习时的推断，分开看。

值得学习的设计 · 事实

  • Schema 即程序：一份 Markdown 同时充当 Agent 指令、LLM 输出 schema 与脚本常量（SCHEMA_FILE），耦合极低。
  • 职责切分：health.py 零 LLM 可高频跑，lint.py 才烧 token——成熟的成本意识。
  • 约束式输出 + 后置校验：强制严格 JSON 并容错剥离代码围栏，写入前再校验断链。
  • 增量与断点续跑：SHA256 缓存 + JSONL 检查点，适合大知识库。
  • 优雅降级：没有 networkx 就关闭社区发现，而不是直接崩溃。

容易踩的坑 · 事实 / 推断

  • [推断] ingest.py 把调试输出写死到 /tmp/...，Windows 上可能失败，建议先改成可配置路径。
  • [事实] graph.html 从 CDN 加载 vis.js，离线会白屏，需要本地化资源。
  • [事实] log.md 文档称 append-only，实现却是前插（newest-first），注意语义不一致。
  • [事实] pdf2md 的 marker 后端会拉 torch 等重依赖，无 GPU 时较慢。
  • [事实] 仓库没有测试与构建 CI，核心的 JSON 解析、wikilink 解析很适合自己补单测。
